# Zsh Server Setup

A lightweight Zsh configuration for Debian/Ubuntu servers.

No Oh My Zsh or other frameworks.

## Included

- Zsh
- zsh-autosuggestions
- zsh-syntax-highlighting
- fzf
- zoxide
- Persistent shell history
- Ctrl+Left / Ctrl+Right word navigation
- Minimal colored prompt
- Separate root prompt

## Install

Clone or copy the files to the server, then run:

```bash
chmod +x setup-zsh.sh
./setup-zsh.sh
```
